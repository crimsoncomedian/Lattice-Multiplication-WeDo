# Lattice Multiplication WeDo

A step-by-step practice page for lattice (Napier's) multiplication. Each problem is random (2×1, 2×2, 3×2 or 3×3 digits).
Students fill in each cell, add along the diagonals, and regroup with the carry boxes. "Show me" fills in the current step,
and once the lattice is finished, back and forward arrows let them review every step.

Everything is in `index.html`. Open it in a browser; nothing is collected or sent anywhere.
